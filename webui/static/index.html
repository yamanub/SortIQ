Models

The SortIQ Pi doesn't train — models are trained on a PC. Install the SortIQ trainer on the PC you use to control the sorter.

Sorting machine

Mirror the machine's live dataset to this trainer — only new images transfer after the first sync, and that first sync can be seeded by copying calibers/ from the machine on a USB stick (the pull then verifies instead of downloading).

Train a new model

Trains the full embedding pipeline on this PC's copy of the dataset: a large teacher network, then the fast student the machine runs. The result is staged as a candidate with its bench numbers — nothing replaces the live model until you install it.

Dataset

The headstamps you've collected images for — click a class to open its images (rename & delete live there). Aim for 300+ per headstamp.
Bars fill toward 500: red — under 10, can't train · amber — 300+, duplicate gate armed · green — 500+, well-fed

Families

A family groups a headstamp's variants under one name — assign it to a slot on the Sort page and every member sorts there (a member with its own slot overrides). Bins and reports only; the model still learns each variant separately.

Dataset maintenance

The health checks and rebuilds. The two scans take a scope — one class right after a session on it (seconds), or the whole dataset for housekeeping. Rebuilds always cover everything.

Slots

dashed = disabled — its stamps are cleared and UNMATCHED relocates; sorting uses only the outlined slots.
Slot calibration (fork firmware) — per-slot arm positions
Absolute arm position per slot, in µsteps from home (16 = 1 full step, 0.1125°/µstep). Jog until the chute centers over its funnel — each press moves the arm there via home so you see the real stop.
Grid setup — rebuilds EVERY slot position
The even grid the table starts from: slot i sits at i × spacing × 16 µsteps. Changing spacing or resetting discards every calibrated position — deliberately tucked away.

Machine settings

firmware auto-detected on connect (stock hides the fork-only tuning) · settings are stored on the Pi and pushed to the board — saving while connected applies immediately

Motion tuning — the knobs you tune with brass running

Machine constants — set once per mechanical build
Leave at defaults unless you know your machine — wrong currents overheat motors or skip steps. Every value is clamped to a safe range on save, so experimenting can't damage anything — and Reset to defaults below always brings back the bench-proven setup.
